# CivicSense AI — Smart Civic Issue Prioritizer

**CivicSense AI** is an AI-powered civic issue management platform designed to help citizens report public problems and help authorities identify, prioritize, and resolve them efficiently.

The platform uses AI to analyze reported civic issues, assess their urgency, and support smarter decision-making for better city management.

## Key Features

- **Civic Issue Reporting:** Submit complaints about problems such as damaged roads, garbage, water supply, and streetlights.
- **AI-Powered Prioritization:** Uses Google Gemini to analyze issues and help determine their priority.
- **Issue Tracking:** Monitor the progress and status of submitted complaints.
- **Smart Dashboard:** View and manage civic issues through an organized interface.
- **Location Support:** Uses Google Maps to support location-based civic issue management.
- **Firebase Integration:** Supports authentication and cloud-based data management.

## Getting Started

### Prerequisites

- Node.js
- npm
- Google Gemini API key
- Firebase project configuration
- Google Maps API key (if using map features)

### Installation

1. Clone the repository:

   ```bash
   git clone git@github.com:umang-shukla-07/CivicSenseAI.git
   cd CivicSenseAI
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Configure the required environment variables using `.env.example` as a reference.

4. Start the development server:

   ```bash
   npm run dev
   ```

Check `package.json` for the available scripts and any additional backend startup instructions.
